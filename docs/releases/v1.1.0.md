# MatManager v1.1.0 · 角料重量与独立桌面版

计算模块独立版升级到 **v1.1.0（公式版本 2.1.0）**：除了预计圆片数量，现在同时给出材料生产后产生的**角料重量**，并提供可直接双击运行的 Windows 桌面版。

## 本次更新

- **角料重量**：双排 = 材料重量 × 0.12，单排 = 材料重量 × 0.22，与所选单重公式无关。
- **参数维护**：新增「单排角料比例系数」「双排角料比例系数」，0–1 可调，共 13 项；旧参数与旧备份自动补齐默认值。
- **全链路展示**：单次结果、批量表、历史详情、复制文本、CSV / XLSX（23 列）与打印全部包含角料数据。
- **Windows 便携 EXE**：单文件、双击运行、内置页面，不需要安装 Node.js、不需要账号与网络。
- **微信小程序版**：新增「圆片算量」工程，与网页/桌面共用同一套公式与参数口径。

## 角料重量口径

| 冲料方式 | 角料比例系数 | 角料重量 |
| --- | ---: | --- |
| 双排 | 0.12 | 材料重量 × 0.12 |
| 单排 | 0.22 | 材料重量 × 0.22 |

示例（201 / 双排 / 厚度 0.3 / 宽度 600 / 重量 100 kg / 第 2 套）：剪口 320 mm，可用重量 82.4 kg，角料 **12 kg**，预计数量 **430 个**。

## 兼容与升级

- 公式版本 2.0.0 及更早的历史记录没有角料快照：详情标注「旧版本记录未含角料数据」，导出时角料两列留空，不按新规则回填。
- 旧参数缓存 / 旧参数 JSON 备份缺少角料字段时，读取和导入时自动补 0.22 / 0.12，不会报「参数格式异常」。
- 桌面版未做代码签名，Windows SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」。
- v1.1.0 桌面版只包含数据计算；v0.2.0 完整版的供应商与材料单据功能未包含，数据互不自动同步。
