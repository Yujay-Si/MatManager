# v0.2.0 发布检查

检查日期：2026-10-09。

## 版本判断与当前功能

适合以v0.2.0发布：本次新增供应商和材料单据两个主要业务模块，保留原数据计算，并兼容原计算历史、参数、桌面来源和用户数据目录。应用版本为0.2.0，计算公式版本仍为2.0.0。

已实现供应商维护及停用、订货/收货/付款/对账、关联收货详情、备份恢复、单据排版及打印。边角料产生、回收销售和收款仅有方案，不包含在本版本。

## 验证范围

- `npm test`：计算、CSV/XLSX、参数、历史、数据迁移、更新策略、Squirrel事件、材料与供应商业务。
- `npm run test:desktop`：菜单实际操作、页面重载、参数下载、打印、写入后重启读取及安装首次启动。
- `npm run test:materials:desktop`：实际录单、关联、编辑、作废、付款、余额、备份、字段集合、四类布局和打印。
- `npm run make`、`npm run test:release-assets`：Windows x64安装版、便携版、RELEASES及nupkg哈希和大小。
- 打包后实际便携EXE：在启动执行前将appData定向到隔离测试目录，通过本机调试接口验证版本、打包路径、430个计算结果、381.25元收货金额、1171.25元余额、6件未收和详情返回。未向日常用户数据库写入样例。
- ASAR包内容与当前业务源码逐文件比较；排除本地备份、工作目录、测试脚本和用户导出数据。

## 升级兼容

仓库与更新地址改为Yujay-Si/MatManager。保留SSMaterialDataCalc程序、Squirrel标识、ssmatcalc页面来源、原本地存储键名、材料IndexedDB名称和Windows用户数据目录。公开附件继续使用旧标识命名，便于旧便携版识别更新。

RELEASES、匹配nupkg、安装EXE、便携ZIP和SHA256SUMS组成完整附件集；发布前通过GitHub API检查上传状态、大小和SHA256摘要。GitHub旧仓库重定向、公开Release和更新源在发布后核验。

升级前分别备份材料、历史和参数。网页与桌面之间仍需手动迁移。程序未签名，Windows可能显示未知发布者。

## 依赖审计限制

`npm audit --omit=dev`报告生产npm依赖0项漏洞。完整npm审计报告33项：3低、4中、25高、1严重，位于现有开发构建工具链。部分修复要求将Electron Forge从7.x跨主版本升级，本次没有执行`npm audit fix --force`，避免未经验证的构建改造。

这是明确保留的维护事项，不能将生产npm审计0项理解为应用全面安全审计通过。npm审计不覆盖随附vendor脚本及Electron内置组件的所有风险。

本机完整审计与打包验收结果位于忽略提交的`work/release-v0.2.0/`，不包含在安装包或仓库源码中。
