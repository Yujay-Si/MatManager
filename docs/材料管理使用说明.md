# 材料管理使用说明

## 打开与录入

源码桌面预览：项目目录运行 `npm start`。离线网页：打开 `outputs/preview-site/index.html`，保持整个页面目录完整。

1. 左侧选择“供应商管理 → 供应商资料”，点“新增供应商 / 期初欠款”。填供应商名称、起算日期、该日开始前的欠款余额。预付余额填负数；联系人、电话、地址、备注可选填。
2. 材料订货单：新增单据，选择供应商与订料日期，添加一条或多条规格明细，单价按元/kg填写。
3. 材料收货单：选择供应商后，每条明细的关联框提示未完成订货规格与未收件数；选择后带入材质、规格、单价。填写件数，以及用空格、逗号或换行分隔的各捆kg重量，填写人工加工进度。保存后按件数扣减订货未收数量。
4. 材料付款单：填还款日期、还款金额、退差金额。页面显示合计及付款前、后的欠款，保存后可打印。
5. 材料对账单：选择供应商、开始与结束日期，点查询。期初包含查询范围前的单据，表格展示每笔增加、减少和累计欠款。可查看原单、导出CSV或打印。

收货可以不关联订货，但会参与供应商欠款。当前系统记录采购与欠款，不计算实际仓库库存。

## 订货单关联收货查询

四类单据按工厂提供的旧系统页面参考重新排版：顶部操作栏、浅色单头、浅绿色明细表头与底部汇总。订货、收货录入使用表格逐行编辑；收货多捆重量仍在同一明细内用空格、逗号或换行录入。付款采用左右分区，合计显示在右上，上期、本期欠款分列底部两侧。对账汇总位于表格底部。所有原字段、校验及计算逻辑保持不变。

明细表在窄窗口内横向滚动，详情和打印则使用换行显示完整字段。工具栏只包含原有功能。打印沿用本工具的打印入口，未增加旧系统截图中的审核、仓库、折扣等字段。

订货列表的摘要显示关联收货单总张数及有效张数。点击订货单“查看”，详情下方的“关联材料收货单”列出收货编号、日期、材质规格、关联件数、重量、金额及状态。每张收货单只列一次，同单内关联本订单的多条明细合并统计。

点击关联行的“查看详情”打开完整收货单，可核对各捆重量、金额、加工进度、订货关联及备注；点“返回订货单”回到原订单。没有关联时明确提示。已作废收货单仍可查看，标注“已作废，不计入已收件数”。

一张收货单包含其他订货单或未关联的明细时，订货详情中的重量、件数、金额只统计本订货单关联部分；完整收货详情则展示整张单据的总计。原有数据直接适用，无需重新录入或迁移。此功能不改写数量和欠款。

## 编辑、作废与期初维护

单据列表提供查看、编辑、作废。作废保留单据记录，并重新核算关联件数和欠款。有效收货仍关联的订货单不能作废，需先处理收货。已作废单据不能再编辑或恢复有效。

在“供应商管理 → 供应商资料”的列表中点“编辑”。修改期初欠款或日期会要求确认，并重新计算余额。起算日期不能晚于现有单据日期。供应商可停用或重新启用；停用后不能用于新增单据，历史记录仍可查询、更正和对账。

同日账目按初次录入顺序排列。付款单的上期、本期欠款指本笔付款前后余额；对账期初、期末欠款指查询期间的开始、结束余额。

## 备份与迁移

“备份材料数据”导出供应商、期初与所有单据的JSON。定期保存至独立目录。

“恢复材料备份”进行合并。完整一致的同编号记录跳过；同编号内容发生变化时取消整个导入，不静默覆盖。不同编号但供应商名称重复也会被拒绝，需核对数据来源。

原计算历史与参数仍通过“数据管理 → 数据计算”中的原入口备份。材料备份不包含计算历史和参数。

桌面安装版、便携版仍使用同一Windows账户的 `SSMaterialDataCalc` 数据目录。网页与桌面不自动同步；迁移需分别导出并恢复材料、计算历史和参数。

## 检查与回滚

- `npm test`：原功能与材料业务规则。
- `npm run test:desktop`：原桌面功能与重启留存。
- `npm run test:materials:desktop`：材料录单、关联、超收拒绝、付款、对账、并发保存和重启留存。

测试使用隔离资料，不写入日常用户数据。验收截图、PDF及临时数据库存于 `work/material-verification/`，不提交。

开发前源码备份位于 `work/backups/20261008-material-management/`。回滚源码前保存当前业务备份，再从该目录恢复相应文件；不要删除用户数据目录。新增的材料数据库不会改写旧计算数据。
