# 订货单关联收货查询

2026-10-08。用户确认后实施。

## 交付

- 订货列表摘要显示关联收货总张数与有效张数。
- 订货详情显示关联收货编号、日期、相关材质规格、件数、重量、金额与状态。
- 同一收货单的多个相关明细合并展示；只计算本订货单的明细。
- 详情按钮打开完整收货单，返回按钮回到原订货详情。
- 空关联有提示；作废关联仍可查看并明确标注，不计入有效收货数量。

不新增数据库字段，不迁移或改写已有单据。数量、金额、欠款继续沿用原计算规则。
