# 供应商管理

2026-10-08新增。左侧模块依次为供应商管理、材料管理、数据管理。各模块标题带下拉箭头，点击可展开或收起；打开模块内页面时自动展开对应子菜单。

## 资料录入与维护

进入“供应商管理 → 供应商资料”，点击“新增供应商 / 期初欠款”。必填名称、期初起算日期、期初欠款；可选填联系人、电话、地址、备注。供应商名称不能重复。

列表中点“编辑”维护资料。沿用原供应商编号，历史订货、收货、付款关联不改变。期初修改仍需确认，并检查日期与旧单据的关系。

旧资料无需重新录入。没有新增字段的资料显示空白，没有状态字段时视为启用。原材料备份继续可导入；新备份同时保存供应商扩展资料与状态，备份版本及数据库名称保持稳定。

## 搜索与欠款

支持按名称、联系人、电话搜索，以及按启用、停用状态筛选。选择欠款截至日期后点“查询 / 更新余额”。欠款包括供应商期初余额，加上截至该日的有效收货金额，减去截至该日的有效还款与退差金额。

截至日期早于期初起算日期时显示“未到起算日期”；负数表示预付款余额。日期更改后先清空旧结果，避免将旧余额误当成新日期的余额。

## 业务查看与状态

点“详情 / 单据”可查看完整资料，以及订货、收货、付款、对账入口。单据跳转自动按该供应商筛选，对账会自动展示其起算日至所选截至日期的账目。单据数量包含作废记录，欠款只计有效记录。

停用供应商会要求确认。停用后保留全部历史关联、欠款和对账；不能创建该供应商的新订货、收货或付款，也不能将另一供应商的旧单据改到停用供应商。仍允许更正本供应商已有历史单据。需要继续交易时重新启用。

本模块使用原材料数据库和备份入口，不新建第二份供应商数据，不增加依赖。
