## 一、先搞清楚 3 件事

| 概念 | 是什么 | 本项目的情况 |
| --- | --- | --- |
| **AppID** | 小程序的唯一身份证，形如 `wx1234567890abcdef` | 已写入 `project.config.json`；换主体时才需要改 |
| **备案** | 工信部 ICP 备案，2023-09-01 起新小程序必须备案才能发布 | 纯工具类，个人主体可备案，一般 1–5 个工作日 |
| **代码包** | 上传到微信服务器的前端代码 | 主包约 112 KB，远低于 2 MB 上限 |

本小程序 **不联网、不登录、不采集任何数据**，所以：

- 不需要买服务器、不需要域名、不需要配置 `request` 合法域名；
- 不需要数据库、不需要云开发；
- 隐私保护指引可以如实选择"不收集用户信息"。

## 第 1 步：注册小程序账号，拿到 AppID

1. 打开 <https://mp.weixin.qq.com/>，点右上角 **立即注册** → 选择 **小程序**。
2. 用一个**从未注册过公众号 / 小程序**的邮箱注册，设置密码，去邮箱点激活链接。
3. 选择主体类型：
   - **个人**：身份证 + 本人微信扫码 + 手机号。个人主体即可发布本工具，足够用。
   - **企业**：营业执照 + 对公账户打款验证（或微信认证 300 元/年），审核更快、可用类目更多。
4. 用**管理员本人微信**扫码登录后台，完成管理员绑定。
5. 进入 **设置 → 基本设置 → 账号信息**，复制 **AppID(小程序ID)**，形如 `wx8f2c1d3e4a5b6c7d`。

> 记住这个 AppID，第 5 步要用。
> 同一时间把同事加为开发者：**管理 → 成员管理 → 项目成员 → 添加成员**，填对方微信号，权限勾选"开发者权限"。

**成功的样子**：后台首页左上角能看到小程序名称，基本设置里能看到 AppID。

## 第 2 步：完成小程序备案（不备案不能发布）

路径：**小程序后台 → 设置 → 基本设置 → 小程序备案 → 去备案**。

1. 填写主体信息：证件类型、证件号、主体名称、证件照片（拍照，四角完整、不反光）。
2. 填写负责人信息：姓名、身份证号、手机号、邮箱（会收验证码）。
3. 填写小程序信息：
   - **服务内容类型**：选「工具」→「效率」或「计算器」类；
   - **服务内容描述**：`提供材料冲片数量的本地计算工具，数据仅保存在用户手机本地，不采集个人信息。`
4. 提交后等平台初审（1–2 天）→ 工信部短信核验（24 小时内点短信里的链接验证）→ 管局审核（1–3 个工作日）。
5. 备案通过后，后台「小程序备案」处会显示备案号，**无需手工填写到代码里**。

> 备案期间可以先做第 4–7 步（开发、上传、提交审核前的预览都可以），只是最后「发布」按钮要等备案通过才可用。

## 第 3 步：设置名称、头像、类目、隐私指引

在 **小程序后台 → 设置** 里依次完成：

1. **基本设置 → 小程序名称**：填 **`圆片算量`**（4 个汉字 = 8 字符，上限 30 字符）。
   - 名称全平台唯一，被占用就换备选：`冲片算量` / `不锈钢算片` / `片数速算` / `冲片助手`。
   - **避开**「数据、统计、信息、管理、平台、中心、系统、服务、政务、监管、认证、全国、中国、官方、国家」等词——它们会把工具类小程序判成「涉及机关/事业单位」，要求提供《组织机构代码证》或《资质授权文件》，直接卡住审核（`数据计算工具` 就是这样被驳回的）。
   - 名称一旦发布，个人主体一年可修改 2 次（企业 5 次，以后台提示为准）；定名前先用微信「搜一搜」查重。
2. **基本设置 → 小程序头像**：正方形 PNG/JPG，建议 144×144 以上；用深绿底 + 白色 Σ 或"材料"字样即可。
3. **基本设置 → 服务类目**：
   - 一级：`工具`
   - 二级：`效率` 或 `计算器`
   - 类目必须和实际功能一致，审核会核对该项。
4. **设置 → 服务内容声明 → 用户隐私保护指引**：
   - 本小程序不采集任何用户信息，指引里如实填写「不收集用户信息」；
   - 若平台强制要求勾选具体接口，只勾选与本项目相关的本地能力说明（无网络接口、无位置/相册/通讯录权限）。
5. **开发 → 开发管理 → 开发设置**：确认 AppID、确认「服务器域名」为空（本项目无请求，留空即可）。

## 第 4 步：安装微信开发者工具并登录

1. 下载稳定版：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>

4. 登录后进入启动页，界面左上角显示当前账号，右侧是「小程序 / 公众号网页 / 小游戏」入口 —— 选 **小程序**。

## 第 5 步：导入项目，确认 AppID

### 5.1 确认 AppID 已写入

`project.config.json` 里的 `appid` 现在已经是你的真实 AppID（形如 `wx5da0788c6d35e8d8`，开发者工具导入时会自动回写）。**只有换主体、换小程序时才需要改**：打开该文件，把 `"appid": "..."` 替换成新的即可。

> 若值仍是 `touristappid`，说明还没填真实 AppID：游客模式只能预览、上传按钮会灰掉。

### 5.2 导入

1. 开发者工具启动页点 **导入项目**（或菜单 项目 → 导入项目）。
2. **目录**：选择 `D:\桌面\文件夹\agent-project\材料数据计算\matmanager-miniprogram`
   （选到含 `app.json` 的那一层，不要选外层「材料数据计算」）。
3. **AppID**：自动读取 `project.config.json`；如果你没改文件，就在这里手动填。
4. **项目名称**：`圆片算量`。
5. **后端服务**：选 **不使用云服务**。
6. 点 **导入**。

**成功的样子**：左侧模拟器出现深绿色标题栏 + 白色卡片，底部四个 tab：单次计算 / 批量计算 / 历史记录 / 参数维护；控制台无红色报错。

> 如果之前误用游客模式打开过，工具会提示「游客模式无法上传」——改完 `appid` 后关闭项目重新导入即可。

## 第 6 步：编译 + 真机自检清单

### 6.1 编译设置

- 顶部工具栏：**编译**（Ctrl+B）一次，确认无报错。
- **详情 → 本地设置**：
  - 调试基础库选 **3.x 稳定版**（例如 3.5.x）；
  - 「将 JS 编译成 ES5」保持勾选（默认）；
  - 「不校验合法域名」**不需要**勾选（本项目零请求）。

### 6.2 模拟器逐项测试

| # | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 单次计算：材质 201、双排、厚度 0.3、宽度 600、重量 100、第 2 套 → 计算 | 预计数量 **430 个**；剪口 320 mm；第 2 套单重 0.1912；角料比例 0.12、角料重量 **12 kg** |
| 2 | 切换冲料方式为单排 | 公式列表多出「第 3 套」；双排时不显示第 3 套 |
| 3 | 厚度留空后点计算 | 红色提示「请输入厚度。」，不产生结果 |
| 4 | 批量计算：粘贴 `材质,厚度(mm),宽度(mm),材料重量(kg),冲料方式,单重公式` + 一行数据 → 计算 | 表格出现 1 行，状态「成功」，提示「成功 1 条」 |
| 5 | 历史记录 | 能看到刚才 1–2 条记录，数量正确；点条目可展开参数快照 |
| 6 | 历史 → 重算 | 新增一条记录，原记录不变 |
| 7 | 参数维护：把「201 第 1 套密度系数」改成 0.8 → 保存 | 弹窗显示 `0.793 → 0.8`；保存后版本变 `v1` |
| 8 | 回到单次计算再算一次 | 结果按新参数变化，参数版本显示「本机参数 v1」 |
| 9 | 参数 → 恢复出厂默认值 | 版本递增、数值回到 0.793 |
| 10 | 单次结果 → 复制结果 | 提示「已复制」，粘贴到聊天可见完整文本 |

### 6.3 真机测试（必做）

点工具栏 **预览** → 手机微信扫码。真机上必须再验这 3 项（模拟器无法覆盖）：

1. **导出 CSV**：单次结果点「导出 CSV」→ 选「发送给朋友」→ 发到「文件传输助手」；
2. **选择文件**：把一份 CSV 发到「文件传输助手」→ 批量计算页点「选择 CSV 文件」→ 从聊天里选中 → 能读出并计算；
3. **数字键盘**：厚度输入框弹出带小数点的数字键盘，能输入 `0.3`。

> `wx.shareFileMessage` **只能在手机微信里用**，开发者工具的模拟器会返回失败，属于正常现象。

## 第 7 步：上传代码

1. 工具栏点 **上传**（右上角，云朵图标）。
2. 填写：
   - **版本号**：`1.0.0`（只能数字和点，且要比上次大）；
   - **项目备注**：`圆片算量首版：单次/批量算片、历史记录、参数维护，纯本地离线`。
3. 点 **上传**，等进度条走完（约 10–30 秒）。
4. 上传成功后，后台 **管理 → 版本管理 → 开发版本** 会出现这条记录，后缀是"开发版"。

> 上传前工具会自动跑一遍打包：主包 112 KB，秒传。
> 如果提示 `Error: appid 与项目不匹配`：回到第 5.1 步改 `project.config.json`。
> 如果提示 `无权限`：让管理员在 **成员管理** 里把你的微信号加为开发者。

---

## 第 8 步：提交审核

1. 登录 <https://mp.weixin.qq.com/> → **管理 → 版本管理**。
2. 找到刚上传的开发版本，点 **提交审核**。
3. 按向导填写：
   - **功能页面**：至少填一个，例如
     - 页面名称：`单次计算`；路径：`pages/single/index`
     - 可再加：`批量计算 pages/batch/index`、`历史记录 pages/history/index`、`参数维护 pages/parameters/index`
   - **测试账号**：本项目无需登录，留空。
   - **补充材料**：可上传 2–3 张模拟器截图（单次计算 + 结果、批量结果、参数维护）。
   - **审核备注**（建议照抄）：
     > 本小程序为纯本地离线计算工具，不联网、不登录、不采集任何用户信息；计算结果仅保存在用户手机本地缓存，用户可自行导出 CSV 备份。
4. 勾选承诺，提交。审核一般 **1–7 个工作日**（工具类常见 1–2 天）。

**常见驳回原因与处理**

| 驳回原因 | 处理 |
| --- | --- |
| 类目与实际功能不符 | 服务类目改成「工具-效率/计算器」，与页面功能一致 |
| 功能不完整 / 页面空白 | 确认上传的是最新代码；确认 `appid` 正确；重新上传再提审 |
| 涉及"数据采集"却未声明 | 隐私保护指引里如实选「不收集用户信息」 |
| 名称含"官方/权威"等敏感词 | 改名后再提审 |
| 未备案 | 先完成第 2 步，备案通过后再发布 |

---

## 第 9 步：发布上线

1. 审核通过后，后台 **版本管理 → 审核版本** 显示「审核通过」。
2. 点 **发布**：
   - **全量发布**：所有用户立刻可用（首版只能全量）；
   - 后续版本可选 **分阶段发布**（按比例放量，出问题可回退）。
3. 发布后，在微信里搜小程序名称即可打开；也可以在小程序后台 **推广 → 小程序码** 下载二维码，发给同事扫码使用。

## 之后每次改版的流程

```
改代码 → 工具里编译自检 → 上传（版本号 +1，如 1.0.1）
      → 后台 版本管理 → 提交审核 → 审核通过 → 发布
```

- 只需重传改动过的文件，微信会自动 diff。
- 每次改动前先跑一遍本地自检，避免把逻辑改坏：

```bash
cd "D:\桌面\文件夹\agent-project\材料数据计算\matmanager-miniprogram"
node test/smoke.js      # 公式/参数/历史/批量/导出 10 项断言
node tools/verify.js    # JSON、WXML 闭合、require 路径、包体积
```

## 数据备份与迁移

### 手机端备份

- **历史记录**：历史记录页 → 「备份 JSON」→ 转发到「文件传输助手」→ 电脑端保存。
- **参数**：参数维护页 → 「备份参数 JSON」→ 同上。

### 从旧 Web 版迁移到小程序

两边 JSON 格式完全一致（`material-calculator-history` / `material-calculator-parameters`，version 1），所以：

1. Web 版点「备份历史 JSON」/「备份参数 JSON」，得到 `.json` 文件；
2. 把文件发到微信「文件传输助手」；
3. 小程序里点「恢复备份」/「恢复参数备份」，从聊天中选中该文件即可。

### 换手机 / 重装微信

本地缓存随之清空。**卸载前务必备份**，到新手机再导入。

### 容量上限

微信给单个小程序的本地缓存是 **10 MB**；历史记录上限 500 条，正常使用只占 1–2 MB。若提示"本地保存失败"，说明缓存将满：先导出备份，再删掉不需要的历史记录。

## 常见问题排查表

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 导入时提示"请选择小程序项目" | 选错了目录层级 | 选到含 `app.json` 的 `matmanager-miniprogram` 目录 |
| 编译报 `app.json` 找不到页面 | 页面文件被误删 | 用压缩包重新解压覆盖 |
| tabBar 图标不显示 | 图片路径或格式问题 | 确认 `images/*.png` 存在；图标必须 PNG，≤40 KB |
| 上传按钮灰色 | 游客模式 / 未登录 / 非开发者 | 填真实 AppID，用管理员或开发者微信登录 |
| 上传提示包体积超限 | 加了图片或第三方库 | 主包上限 2 MB，大文件放分包或用 CDN |
| 真机点"导出 CSV"没反应 | 微信版本过旧 | 升级微信；`wx.shareFileMessage` 需 2.11.0+ |
| 电脑端工具里"选择文件"读不到数据 | 模拟器不支持聊天选文件 | 必须真机预览测试 |
| CSV 打开是乱码 | 文件不是 UTF-8 | 小程序导出的 CSV 带 BOM，用 Excel 直接打开即可；自制的 CSV 请另存为"CSV UTF-8" |
| 输入 0.3 变成 03 或不显示小数点 | 输入框类型用错 | 本项目已用 `type="digit"`，如自行改过请恢复 |
| 计算提示"宽度过小，最终剪口为 0 mm" | 宽度小于剪口步长 | 属正常业务校验，输入更大宽度 |
